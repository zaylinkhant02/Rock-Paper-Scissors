# rock-paper-scissors
A command-line Rock Paper Scissors game with three AI difficulty levels, score tracking, and win streak tracking, made using C.

## Overview

A CLI implementation of Rock Paper Scissors with three difficulty modes - Easy (random), Medium (counter-picking), and Hard (pattern detection). The program tracks wins, losses, ties, win rate, and longest win streak.

## Technologies Used

![C](https://img.shields.io/badge/C-00599C?style=flat&logo=c&logoColor=white)

- C (Standard Library only)
- CLI interface

---

## Features

- Three difficulty levels:
  - **Easy** - Pure random moves
  - **Medium** - Counter-picks 50% of the time
  - **Hard** - Detects and counters your most frequent move
- Score tracking (Wins / Losses / Ties)
- Win rate percentage
- Longest win streak tracking
- Input validation
